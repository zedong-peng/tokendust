How much AI do you actually use?

One command per machine, then drop the files here. The board sums them, prices the tokens at API list rates, and draws one shareable card. The scan happens on your machine and the merge happens in this tab — nothing is uploaded, and there is no account.

1 Run this on each machine you code on 
curl -fsSL https://zedongpeng.com/tokendust/scan.py | python3 -

Python 3.8+, nothing to install, reads the logs already on disk. Writes tokendust-<machine>.json next to you. Add --cursor to include Cursor’s dashboard (the only network call). Prefer a file? Download scan.py.

2 Drop the tokendust-*.json files here

One per machine. Repeated scans of the same machine are fine — the board keeps the larger count.

      Your share card

      Carries the tokendust name and link, so the picture answers “how did you make this?” without a caption.

      What is counted
      Claude Code, Codex, OpenCode and Gemini CLI read their local logs; Cursor is read from its dashboard when you pass --cursor. Anything that only exists in a browser has no local log, so it is not counted — a flat subscription is not a token count.
      Why the dollars are not your bill
      Every number is priced at the official API list rate. On a subscription the real bill is smaller, sometimes by a lot. The point is the quantity, not the invoice.
